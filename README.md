# TeamSN CSE323 222D4 Project Codebase

## Description

This project implements a **Login & Signup System with AES and RSA encryption** using Flask (Python). The system allows users to securely sign up, log in, and encrypt or decrypt messages using AES and RSA encryption algorithms. It provides a user-friendly interface for encryption and decryption tasks, and uses JSON for storing user credentials securely.

Key features of this project:
- **User Authentication**: A secure sign-up and login system.
- **AES Encryption/Decryption**: Allows users to encrypt and decrypt messages using the AES algorithm.
- **RSA Encryption/Decryption**: Provides functionality for encryption and decryption using RSA algorithm.
- **JSON-based User Data Storage**: User credentials are stored in a `users.json` file, with passwords hashed using SHA-256.
- **Frontend**: Simple and intuitive frontend created with HTML, CSS, and JavaScript.
